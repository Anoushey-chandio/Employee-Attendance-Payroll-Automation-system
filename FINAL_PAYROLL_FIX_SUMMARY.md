### 1. DATABASE CHECKOUT LOGIC ✅
**File: `services/attendance_service.py`**


## SQL Verification

### Check COMPLETED Status
```sql
SELECT 
    u.full_name,
    a.date,
    a.status,
    a.check_in,
    a.check_out,
    a.regular_hours,
    a.overtime_hours,
    u.hourly_rate
FROM attendance a
JOIN users u ON a.user_id = u.id
WHERE a.check_out IS NOT NULL
ORDER BY a.date DESC
LIMIT 10;
```

**Expected:** All checked-out records show `status = 'completed'`

### Verify Earnings Match
```sql
SELECT 
    full_name,
    date,
    regular_hours,
    overtime_hours,
    hourly_rate,
    (regular_hours * hourly_rate) as regular_pay,
    (overtime_hours * hourly_rate * 1.5) as overtime_pay,
    (regular_hours * hourly_rate) + (overtime_hours * hourly_rate * 1.5) as total_pay
FROM attendance a
JOIN users u ON a.user_id = u.id
WHERE a.status = 'completed'
AND a.date >= DATE('now', '-30 days')
ORDER BY a.date DESC;
```
